# Code of Conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

**In short:** be kind, assume good faith, critique code rather than people, and make room for newcomers. Harassment, insults and personal attacks aren't tolerated in issues, pull requests, discussions or any other project space.

**Reporting:** contact the maintainer privately through a [GitHub Security Advisory](https://github.com/X-Saikat-93/embermeter/security/advisories/new) (it's private) and mark it as a conduct report. Reports are kept confidential.

**Enforcement:** the maintainer may edit or remove content, or warn, suspend or ban a contributor, following the Covenant's [enforcement guidelines](https://www.contributor-covenant.org/version/2/1/code_of_conduct/#enforcement-guidelines).
